Kikosi Website Project Notes

This document summarizes the full project workflow, from creating the React app to deployment on GitHub and Vercel.

1. Project Setup

npm create vite@latest kikosi-site -- --template react
cd kikosi-site
npm install

2. Copy Original Static Files

  • Copy the CSS file from the original static site into the React app.
  • Copy images and assets into the new project folder.
copy C:\Users\user\Desktop\kikosi-website\css\styles.css C:\Users\user\Desktop\kikosi-site\src\styles\index.css
robocopy C:\Users\user\Desktop\kikosi-website\assets C:\Users\user\Desktop\kikosi-site\src\assets /E

3. Convert to React Components

  • Header
  • HeroSection
  • AboutSection
  • StatsSection
  • EventsSection
  • CalendarSection
  • LeadershipSection
  • FaqSection
  • DonateSection
  • Footer

4. Keep Repeated Data in Arrays

Best practice: keep repeated card content in data files instead of copy-pasting in components.

  • leaders.js
  • posters.js
  • faqs.js

5. Move Logic into Hooks

  • useMenuToggle for mobile menu behavior
  • useCountdown for event countdown logic
  • useCarousel for auto-scrolling carousel behavior

6. Carousel Fix

The carousel should:

  • auto-scroll every few seconds
  • pause on hover, focus, or touch
  • resume after a short delay
  • loop back to the start
  • use actual width and scroll values
const maxScroll = Math.max(node.scrollWidth - node.clientWidth, 0);

if (node.scrollLeft >= maxScroll - 2) {
  node.scrollTo({ left: 0, behavior: 'smooth' });
  return;
}

step(1);

7. Improve Accessibility & SEO

  • clear focus states for keyboard users
  • semantic headings
  • good contrast and readable text
  • meaningful page title
  • meta description
  • Open Graph tags
  • favicon and web manifest
  • robots.txt and sitemap.xml

8. Build the Site

npm run build

Successful output should look similar to:

vite build
✓ built in 651ms

9. Run the Local Preview

npm run dev -- --host 0.0.0.0

Then open:

http://localhost:5173/

10. Push to GitHub

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <your-github-repo-url>
git push -u origin main

11. Deploy to Vercel

  1. Open Vercel
  2. Click New Project
  3. Import the GitHub repository
  4. Use the default Vite/React settings
  5. Deploy

12. Best-Practice Website Checklist

  • Mobile layout works well
  • No broken links
  • Buttons and menu work correctly
  • Carousel works smoothly
  • Page title and meta description are correct
  • Images are optimized
  • Site is keyboard-friendly
  • Preview cards look good when shared

13. Final Summary

The project was migrated from a static website into a Vite + React app, improved for quality and SEO, and prepared for GitHub + Vercel hosting. The main technical fix was making the carousel auto-scroll correctly without relying on a guessed fixed distance.
