# Archived React/Vite project

This folder preserves the React/Vite version from `backup-origin-main` for reference. The active website remains the static site in the repository root; this archived project is not used by the root Vercel deployment.

To run this archived version locally, open a terminal in this folder and run:

```powershell
npm install
npm run dev
```
